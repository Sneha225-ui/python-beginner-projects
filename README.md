# Python Beginner Projects

A collection of beginner-level Python projects created for learning and practice.

## Projects Included

### 1. Calculator

A basic command-line calculator that performs addition, subtraction, multiplication, and division.

## Features

* Supports `+`, `-`, `*`, and `/`
* Takes user input
* Displays results rounded to 3 decimal places
* Handles invalid operators

## Usage

Run the program and enter an operator and two numbers when prompted.



### 2. Quiz Game

A simple command-line quiz game. Users answer multiple-choice questions and receive a final score based on their correct answers.

## Features

* Multiple-choice questions
* Instant feedback for each answer
* Displays correct answers
* Calculates and shows final score percentage



### 3. Shopping Cart

A simple shopping cart application that allows users to add food items and their prices, then calculates and displays the total bill.

## Features

* Add multiple food items
* Store item names and prices
* Calculate total cost automatically
* Display purchased items and final bill


### 4. Food Ordering System

Allows users to order food through a menu-driven interface
A simple Python menu-based ordering system that allows users to select food items, add them to a cart, and calculate the total bill.

## Features

* Displays a menu with prices
* Allows multiple item selection
* Stores selected items in a cart
* Calculates and displays the total cost



### 5. Temperature Converter

A simple Python program that converts temperatures between Celsius and Fahrenheit based on user input.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* User-friendly input
* Handles invalid temperature units
  


### 6. Weight Converter

A simple Python program that converts weight between kilograms (kg) and pounds (lbs). Users can perform multiple conversions until they choose to quit.

## Features

* Convert kilograms to pounds
* Convert pounds to kilograms
* Continuous conversion mode
* Handles invalid unit input

## About This Repository
This repository contains beginner-friendly Python projects created to practice fundamental programming concepts such as loops, conditionals, lists, dictionaries, and user input handling.
