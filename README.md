# Python Beginner Projects

A collection of beginner-level Python projects created for learning and practice.

## Projects Included

### 1. Calculator
Performs basic arithmetic operations.

### 2. Quiz Game
A simple question-and-answer game.

### 3. Shopping Cart
Simulates a shopping cart system.

### 4. Food Ordering System
Allows users to order food through a menu-driven interface.

### 5. Temperature Converter
Converts temperatures between Celsius and Fahrenheit.

### 6. Weight Converter
Converts weights between different units.

## Skills Practiced
- Variables
- Data Types
- User Input
- Conditional Statements
- Loops
- Functions
